Typefaces

Merriweather, Playfair Display, Inter, Outfit, Fredoka, Heebo, and Vazirmatn are bundled with the app under the SIL Open Font License 1.1 (packaged via the Fontsource project, MIT). Heebo and Vazirmatn are used for Hebrew and Farsi/Arabic text.

Dictionary data

  • Online definitions are provided by the Free Dictionary API, whose data is sourced from Wiktionary (Creative Commons BY-SA).
  • The bundled offline dictionary is derived from Webster's Unabridged Dictionary (1913 edition), which is in the public domain.

Services

  • Free Dictionary API — word definitions.

  • MyMemory Translation API (Translated S.r.l.) — fallback in-app translation on platforms without Chrome's on-device Translator API (Android, iOS, Safari, Firefox).
